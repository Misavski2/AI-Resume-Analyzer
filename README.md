# AI Resume Analyzer

> **Status:** This project has been in development

### How it will work? 
 The AI Analyzer it's an API where you can upload your resume in PDF format. The API reads the resume, compares it to a job description and then sends back a score.

### Architecture 
Currently, using Clean Achitecture and DDD (Domain-Driven Design) to ensure a highly maintainable and scalable system.

### Tech Stack
 - Using C# and .NET powering the backend logic.
 - Google Gemini 1.5 Flash as a IA Analyzer
 - React in the frontend (Coming soon)
